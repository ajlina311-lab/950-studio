# 950 Studio

[中文说明](README.zh-CN.md) · [Report an issue](https://github.com/ajlina311-lab/950-studio/issues/new/choose) · [Releases](https://github.com/ajlina311-lab/950-studio/releases) · [Community](docs/COMMUNITY.md)

950 Studio is an interface project for AKAI S950 users. It is currently in development, with a free public beta planned.

## Download

**Public beta build coming soon.** No public installer has been released yet.

Downloads will be published through [Releases](https://github.com/ajlina311-lab/950-studio/releases). Each release will include its supported systems, setup instructions and known limitations.

## Feedback

We welcome feedback in **English or Chinese**. [Open the feedback forms](https://github.com/ajlina311-lab/950-studio/issues/new/choose) and choose:

- **Bug report** — a problem you encountered, with steps and setup details.
- **Feature request** — a real task you want to complete and what could make it easier.
- **User test** — what worked, where you got stuck and what you would improve first.

See the [feedback guide](CONTRIBUTING.md) for details. Once a beta is available, the [user testing guide](docs/TEST_GUIDE.md) provides a few short tasks to try.

## Community

A Discord community is being prepared for setup questions, feedback, testing and sharing music or workflows. Its invitation will be added to the [community page](docs/COMMUNITY.md) when it is ready.

## Project updates

This page will be updated as development progresses. Public builds and their changes will appear in **Releases**, while specific problems and improvements will be tracked in **Issues**.
