# 950 Studio

**公测提醒：950 Studio 可能导致 AKAI S950 死机。请在测试前保存当前 Program，编辑过程中也要及时保存。如果 S950 无响应，目前已知的恢复方法是在 S950 本机重启。**

[English](README.md) · [提交反馈](https://github.com/ajlina311-lab/950-studio/issues/new/choose) · [版本下载](https://github.com/ajlina311-lab/950-studio/releases) · [Discord](https://discord.gg/AunScWHVu) · [社群](docs/COMMUNITY.md)

950 Studio 是面向 AKAI S950 使用者的界面工具项目。

## 下载

**S950 Studio v1.3.21 正式版（Build 36）** 适用于运行 macOS 13 或更新版本的 Apple Silicon Mac。[下载应用 ZIP](https://github.com/ajlina311-lab/950-studio/releases/download/v1.3.21/S950-Studio-v1.3.21-macos-arm64.app.zip)。应用采用 ad-hoc 签名，未经 Apple 公证。[正式版发布页](https://github.com/ajlina311-lab/950-studio/releases/tag/v1.3.21) 提供源码 ZIP、`SHA256SUMS.txt` 和已知限制说明。

## 反馈

欢迎使用**中文或英文**反馈。[打开反馈表单](https://github.com/ajlina311-lab/950-studio/issues/new/choose)，选择：

- **问题反馈**：描述实际遇到的问题、操作步骤和设备环境。
- **改进建议**：说明想完成的真实任务，以及怎样能更方便。
- **使用测评**：记录哪些操作顺利、在哪里卡住，以及最希望优先改善的地方。

具体填写方式见[反馈说明](CONTRIBUTING.md)。测试版发布后，可以参照[首次试用指引](docs/TEST_GUIDE.md)完成几个简短任务。
