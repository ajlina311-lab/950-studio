# 950 Studio

[English](README.md) · [提交反馈](https://github.com/ajlina311-lab/950-studio/issues/new/choose) · [版本下载](https://github.com/ajlina311-lab/950-studio/releases) · [社群](docs/COMMUNITY.md)

950 Studio 是面向 AKAI S950 使用者的界面工具项目，目前正在开发中，计划提供免费的公开测试版。

## 下载

**测试版准备中。** 目前尚未发布公开安装包。

后续安装包将通过 [Releases](https://github.com/ajlina311-lab/950-studio/releases) 发布，每个版本会附上支持系统、安装与连接说明，以及已知限制。

## 反馈

欢迎使用**中文或英文**反馈。[打开反馈表单](https://github.com/ajlina311-lab/950-studio/issues/new/choose)，选择：

- **问题反馈**：描述实际遇到的问题、操作步骤和设备环境。
- **改进建议**：说明想完成的真实任务，以及怎样能更方便。
- **使用测评**：记录哪些操作顺利、在哪里卡住，以及最希望优先改善的地方。

具体填写方式见[反馈说明](CONTRIBUTING.md)。测试版发布后，可以参照[首次试用指引](docs/TEST_GUIDE.md)完成几个简短任务。

## 社群

Discord 社群正在准备，用于操作求助、反馈、测试，以及分享音乐和工作流程。准备好后会在[社群页面](docs/COMMUNITY.md)提供邀请链接。

我们会随开发进展更新本页。公开版本及变更记录会发布在 **Releases**，具体问题和改进在 **Issues** 中跟进。
