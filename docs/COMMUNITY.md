# Community / 社群

[Project home / 项目首页](../README.md) · [Feedback guide / 反馈说明](../CONTRIBUTING.md)

## Join Discord / 加入社群

[Join the 950 Studio Discord community / 加入 950 Studio Discord 社群](https://discord.gg/AunScWHVu)

Ask setup questions, share feedback, take part in real-world testing, and share music or workflows. English and Chinese are both welcome.

这里用于操作求助、使用反馈、实际测试，以及分享音乐和工作流程。英文和中文都可以。

## Where to post / 选择反馈入口

| What you want to share / 内容 | Where to go / 入口 |
| --- | --- |
| Setup questions, quick feedback, music and workflows / 操作求助、简短反馈、音乐与工作流程 | [Discord](https://discord.gg/AunScWHVu) |
| Bug reports, feature requests and structured user tests / 问题反馈、改进建议与完整使用测评 | [GitHub feedback forms / GitHub 反馈表单](https://github.com/ajlina311-lab/950-studio/issues/new/choose) |

If you prefer to start a conversation, any of these topics can begin in Discord. Submit your feedback once in whichever place you prefer; maintainers will link work that needs tracking to a GitHub Issue and share progress in the original conversation.

如果更习惯直接交流，以上内容也都可以先在 Discord 提出。任选一个入口反馈一次即可；需要持续跟进的问题由维护者关联到 GitHub Issue，并在原处同步进展。

For details that help us follow up, see the [feedback guide](../CONTRIBUTING.md). / 需要提供哪些信息，见[反馈说明](../CONTRIBUTING.md)。
