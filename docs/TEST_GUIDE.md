# User Testing Guide / 首次试用与测评

[Project home / 项目首页](../README.md) · [Feedback guide / 反馈说明](../CONTRIBUTING.md)

This guide is for the public beta. Follow the selected release's requirements and choose one supported workflow that you would actually use.

**Public beta warning: 950 Studio may cause your AKAI S950 to freeze. Save your Program before testing and regularly as you edit. If the S950 stops responding, the only recovery method we currently know is to restart the sampler itself.**

这份指引用于公开测试。请以选定版本的要求为准，选择一项实际会用到且已经支持的操作。

**公测提醒：950 Studio 可能导致 AKAI S950 死机。请在测试前保存当前 Program，编辑过程中也要及时保存。如果 S950 无响应，目前已知的恢复方法是在 S950 本机重启。**

## Record your setup / 记录环境

Note the app version, operating system, computer architecture if known, and equipment or connection setup. If you do not have an S950, identify any hardware-dependent steps you did not test.

记录软件版本、操作系统、电脑架构（如知道）及设备连接方式。没有 S950 实机时，请说明哪些硬件相关步骤没有测试。

## Three short tasks / 三个简短任务

1. **Get started / 开始使用。** Follow the release's setup guide and note where you need extra help. / 按该版本指南安装和设置，记录需要额外帮助的步骤。
2. **Complete a real task / 完成真实任务。** Try one supported workflow with replaceable test material. Record the result and approximate time. / 使用可替换的测试素材完成一项已支持操作，记录结果和大致耗时。
3. **Compare with your usual method / 比较原来的做法。** What is easier, what is harder, and what would stop you using the tool? / 哪一步更方便，哪一步更麻烦，什么问题会影响你继续使用？

## Tell us / 希望得到的反馈

- What did you try? / 实际尝试了什么？
- Did you finish? Where did you get stuck? / 完成了吗，卡在哪里？
- What was most useful? / 最有用的一点是什么？
- What caused the most friction? / 最影响使用的一点是什么？
- What should we improve first? / 下一版最希望优先改善什么？

A short recording or screenshot is welcome. Submit a **User test** or **Bug report** through the repository's Issues menu, in English or Chinese.

欢迎附上短录屏或截图。在仓库 Issues 中提交 **使用测评** 或 **问题反馈**，英文和中文都可以。

You can also share your experience in [Discord](https://discord.gg/AunScWHVu). Choose one place to submit; there is no need to repeat your feedback in both.

也可以在 [Discord](https://discord.gg/AunScWHVu) 交流试用体验，任选一个入口提交即可，无需重复反馈。
