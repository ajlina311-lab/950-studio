# Feedback Guide / 反馈说明

[Project home / 项目首页](README.md) · [Discord](https://discord.gg/AunScWHVu)

English and Chinese are both welcome. Please describe what you actually tried; it is fine to leave unknown details blank where the form allows it.

欢迎使用英文或中文。请描述实际尝试过的操作，不确定的信息可以在表单允许时留空。

## Choose a form / 选择表单

Open the [feedback forms](https://github.com/ajlina311-lab/950-studio/issues/new/choose), then choose the form that fits your feedback.

打开[反馈表单](https://github.com/ajlina311-lab/950-studio/issues/new/choose)，选择对应类型。

| Form / 表单 | Use it for / 适合内容 |
| --- | --- |
| Bug report / 问题反馈 | Something behaved unexpectedly / 操作结果与预期不符 |
| Feature request / 改进建议 | A task or workflow you want to improve / 希望改善的任务或工作流程 |
| User test / 使用测评 | The outcome of a real testing session / 一次真实试用的体验与结果 |

## Make a report useful / 怎样更便于跟进

- Include the app version or build filename, your operating system, and any equipment or connection setup involved. / 尽量提供软件版本或文件名、操作系统，以及相关设备与连接方式。
- For a problem, describe the steps, what you expected and what happened. / 问题反馈请说明步骤、预期结果与实际结果。
- For a suggestion, explain the task and the benefit you hope for. / 功能建议请说明使用场景和希望得到的帮助。
- For a test, tell us what you completed, what was useful and the biggest obstacle. / 使用测评请说明完成了什么、最有用的地方和最大的阻碍。
- A relevant screenshot or short recording can help. Use material you are comfortable sharing publicly. / 可以附相关截图或短录屏，请使用可以公开的内容。

Please keep one problem or suggestion per issue. If you find an existing issue about the same topic, add your setup and observations there.

一条 Issue 尽量描述一个问题或建议。如已有相同主题，可在原 Issue 补充设备环境和观察结果。

## Follow-up / 后续跟进

Maintainers may ask for more details, link duplicate reports or request a retest after a fix. Confirmed changes will be documented in the relevant release notes.

维护者可能会补充询问、关联重复反馈，或在修复后邀请复测。已发布的改动会写入对应版本说明。

You may also share feedback in the [Discord community](https://discord.gg/AunScWHVu). Submit once in whichever place you prefer; maintainers will link work that needs tracking to an Issue and share progress in the original conversation.

也可以直接在 [Discord 社群](https://discord.gg/AunScWHVu)反馈。选择一个入口提交一次即可；需要持续跟进的问题由维护者关联到 Issue，并在原处同步进展。
